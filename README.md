This is a utility for fighting [ghost-type enemies](https://woh.fandom.com/wiki/Ghosts) in the game [World of Horror](https://wohgame.com/).
It is a Mastermind-like minigame where the player needs to enter a series of 5 actions (bows or claps) in a specific order and the game will tell them how many were in the correct position.

The webpage is available at https://crushakrool.github.io/world-of-horror-exorcism-solver/.
